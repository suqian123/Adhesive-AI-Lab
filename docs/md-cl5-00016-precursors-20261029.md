# CL5-00016 氰酸酯/二硫键 MD 前体

本记录是建模准备，尚不是经过验证的生产 MD 输入。配方指纹为 `FMT-553A4410C5387F8A`。

该指纹来自原有候选库的概括性配方，并不包含本次新增的单体身份、质量比和 CTBN 链结构。正式结果回写前，需要先将具体配方纳入候选身份并生成新的配方指纹，避免将不同模型混为同一配方。

用户指定两种氰酸酯单体的进料质量比为 BADCy:DCDDS = 79:21，并在每 100 份树脂中加入 5–10 份 CTBN。此处以 5 phr 为起始模型。BADCy 和 4,4′-二氰酸酯二苯二硫（DCDDS）的结构按用户提供的化学名称构建；经 RDKit 检查，二者均有两个氰酸酯基，DCDDS 含一个二硫键。已生成单体的三维 SDF/PDB，几何优化仅用于构型准备，不构成生产力场验证。

CTBN 采用 Hypro 1300X13。供应商产品页列出的典型分子量约 3150 g/mol、平均官能度 1.8；供应商资料列出的丙烯腈典型含量约 26%。用户给出的约 3500 g/mol 和双端羧基可作为近似参考，实际批次以 TDS/CoA 为准。代表链选择 42 个 1,4-丁二烯单元、15 个丙烯腈单元和两个羧基端基，分子量约 3172 g/mol，丙烯腈重复单元质量分数约 25.95%。这是单条理想化代表链：序列均匀、丁二烯顺反构型未指定，不能代表实际分子量、序列、端基和微观结构分布。

有限体系提案含 181 个 BADCy、44 个 DCDDS 和一条上述 CTBN 链，树脂质量比约 79.22:20.78，CTBN 为 4.988 phr。用户同意将筛选任务的数值作为氰酸酯基转化率的建模假设。450 个氰酸酯基按三个一组形成三嗪环时，有限体系对应：

这些数字是计数方案，尚未生成三维交联网络。还需要构建和检查成键、CTBN 与树脂的连接或相态、反应前后原子类型与电荷、二硫键交换模型，完成力场及物性验证；界面仍需经验证的 PDA/CeO₂ 和跨界面参数。当前没有生产批准，也没有创建 `system.data` 或 `forcefield.production`。
