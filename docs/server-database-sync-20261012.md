## 本机连接

本机当前连接为 `127.0.0.1:13306` → SSH `user@119.147.202.74:8005` → 服务器 `127.0.0.1:3306`。使用独立数据库账号，仅授权 `adhesive_ai_lab`。密码保存在忽略提交的 `.env` 中。

本次操作已启动后台数据库隧道。电脑重启或隧道断开后，在项目 PowerShell 中执行以下命令并保持终端运行：

```powershell
.\run_server_tunnel.ps1
```

该命令同时转发数据库 `13306` 和服务器网页 `18501`，网页地址为 `http://127.0.0.1:18501`。如果已有网页隧道，只重建数据库隧道：

```powershell
.\run_server_tunnel.ps1 -DatabaseOnly
```

已有隧道正常运行时无需重复启动；同一本地端口只能由一个隧道占用。专用密钥保存在忽略提交的 `work/server_access/`，服务器限制该密钥只能转发 MySQL 和网页端口。服务器管理仍使用原密码登录方式。

本机 `.env` 已清空旧 `DATABASE_URL`，改用 `MYSQL_*` 共享主库配置，并设置 `ADHESIVE_SQLITE_FALLBACK=0`。断线时数据库操作报错，不再写入独立 SQLite。断网不会停止服务器应用及服务器上的任务；本机需恢复网络和隧道才能继续访问。若本地网页进程在迁移前已启动，重启本地 Streamlit 以加载新连接配置。

数据库提交后，两端连接立即能读取新记录；已打开页面需要刷新才能重新加载显示。任务目录、计算日志和迁移后新生成的模型文件仍存于生成它们的主机，本次没有设置持续文件同步。建议在服务器网页执行计算和模型归档。
