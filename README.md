# 粘附材料 AI 辅助分子模拟预测

面向粘附材料配方早期筛选的 Python + Streamlit MVP。

## 功能

- 输入树脂、增粘剂、填料的 SMILES 和质量配比
- 提取轻量分子结构特征
- 训练可版本化的回归/分类代理模型，预测宽温域黏附、自修复、抗原子氧、抗紫外和增材制造指标
- 为每个候选生成稳定的配方指纹（`FMT-...`）和候选库版本，并写入 MySQL 候选表
- 生成 PDA@CeO₂ 粗粒化界面拓扑，并支持外部 LAMMPS/GROMACS 任务提交和输出回读
- 为单个候选生成覆盖 CeO₂ 晶面/氧空位/羟基化、PDA 结合、交联树脂温度扫描、界面 MD 和粗粒化模拟的多尺度任务包
- 提供两种多尺度运行方式：本地“一键生成并启动多尺度计算”按依赖关系以最多 16 个并行任务后台调度；“登记并导出外部计算任务包”不启动本机求解器，供集群或其他工作站计算后上传结果回写
- 批量导入实验 CSV 或回写单条实验数据，记录代理/外部计算/实验来源，并自动更新、归档和推荐下一轮实验
- 提供“外部计算可视化”页面，跨候选查看任务状态、运行目录、结构化结果、DFT/MD 图表和原始日志
- 展示能量轨迹、表面覆盖率、分子特征和特征重要性

当前默认页面仍使用明确标记的物理启发代理结果进行前筛；只有提交并完成 VASP/QE/CP2K/LAMMPS/GROMACS 外部任务后，结果才可作为真实计算数据回写候选库。正式 AI 筛选与模型归档要求至少一个候选已完成外部计算回写；“当前候选 AI 评估”绑定当前多尺度候选，且仅在该候选已有外部回写或实验记录时显示。出于候选绑定规则，当前候选没有真实回写时，不显示全局候选排序、下一轮实验推荐或重训入口；当前候选已有真实回写且模型已完成外部计算校准后，才展示全候选库排序。数据回写或页面重开时会自动加载和更新最新归档结果。

每个候选由“候选编号 + 配方指纹 + 候选库版本”共同标识。配方指纹由树脂/共混比例、动态键、固化体系、增韧剂、PDA@CeO₂ 填料和交联密度等配方契约计算 SHA-256 后生成。候选表、外部计算结果和实验结果均保存该身份信息；不匹配的记录不会回写到当前候选，历史结果会保留。

“多尺度计算任务包”是可复现的计算清单和数据契约，不虚构真实计算结果。其中粗粒化起始模型可直接生成；真实 DFT 和全原子 MD 在运行前仍需提供经验证的 CeO₂/PDA/树脂结构、交联拓扑、力场、DFT(+U) 参数及计算软件环境。VASP 收敛验证按 CeO₂(111)、CeO₂(110)、CeO₂(100) 分别进行，只有对应晶面的验证报告批准后才会提交生产 DFT。MD 输入通过静态检查后，仍需带文件哈希的拓扑、力场和物性验证批准才能提交生产任务。

“候选结果汇总与综合分析”绑定当前多尺度计算候选，自动融合实验记录、外部 DFT、树脂 MD、界面 MD 和模型预测。融合优先级为实验 > 外部计算 > 代理；每个指标单独记录来源，外部计算没有输出的字段不会被误标为真实数据。标量 MD 数据只作为 25°C 锚点，温度曲线的代理部分会标记为混合来源。

主页面按六个板块组织：候选数据库生成 → 多尺度计算方案 → 外部计算任务与结果回写 → 候选结果汇总与综合分析 → AI 筛选与候选排序 → 实验验证、实验回写与模型更新。页面的“需求实现与科学就绪状态”将实现、外部环境和科学验证边界分开显示。

## 闭环流程与数据时序

页面从上到下表示一次材料研发迭代，而不是把实验数据错误地放在计算之前：

1. 候选数据库：生成配方、特征、代理前筛结果以及“候选编号 + 配方指纹 + 候选库版本”身份。
2. 多尺度计算方案：为当前候选生成 DFT、树脂 MD、界面 MD 和粗粒化任务包；只有真实结构、力场、软件环境和科学批准条件满足后，任务才可执行。
3. 外部计算任务与结果回写：平台可本地调度、单任务提交，或登记任务包后在外部集群导入结果；解析后先校验候选身份，再写入计算结果历史和候选库。外部任务包会记录运行编号、候选身份、所选引擎和预期结果文件，登记本身不启动本机求解器，也不占用本地启动锁。主页面的“查看多尺度运行记录”只负责当前候选的运行状态与终止；第 3 板块只处理导入、单任务和回写，跨候选监控统一在“外部计算可视化”页面进行。反向切换“方案候选编号”会清除旧运行选择，并同步筛选下游单独任务、结果汇总与综合分析。
4. 候选结果汇总与综合分析：读取此前已沉淀的实验与计算结果，按“实验 > 外部计算 > 代理”逐指标融合；没有真实输出的字段仍明确标为代理或混合数据。
5. AI 筛选与候选排序：基于当前已沉淀数据给出当前候选评估，并在满足候选绑定和外部计算校准门槛时显示全局排序。
6. 实验验证、实验回写与模型更新：对本轮选择的候选实施实验，录入单条记录或 CSV；系统保存实验数据、重新训练并刷新页面。刷新后的第 4、5 板块即构成下一轮迭代的融合和筛选输入。

因此，实验验证位于页面末端是有意的：它是本轮计算和推荐的验证环节，同时也是下一轮模型更新的最高优先级数据源。实验结果在提交时立即持久化和重训，但前面已渲染的融合、排序内容会在自动刷新后反映该结果。

当前有两项明确的策略门槛：即使已有实验数据，正式 AI 模型仍要求至少一个候选存在已回写外部计算；全局排序又要求当前页面所选候选已有真实回写。这两项规则用于防止未校准的代理推荐被误作真实结论，但也会限制在未验证候选间直接浏览全局推荐的能力。

## 启动

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

浏览器打开 `http://localhost:8501`。

## 网络受限时的离线启动

如果无法安装 Streamlit、Plotly 或 Pytest，可以直接运行：

```powershell
.\run_offline.ps1
```

浏览器打开 `http://127.0.0.1:8765`。这个版本使用 Python 内置 HTTP 服务和原生 Canvas，复用同一套 AI 预测与粗粒化模拟核心，不需要访问 PyPI。

pytest

## 配置说明

- 复制 `.env.example` 为 `.env`，再填写 MySQL 连接信息；也可以使用 `DATABASE_URL=mysql://用户:密码@主机:端口/数据库`。
- 首次配置后运行 `python scripts/init_database.py`，创建数据表、身份字段与索引，并验证读写权限。已有 MySQL 表会以非破坏方式补充候选表的 `formulation_id`、`candidate_library_version` 和配方指纹索引。
- 默认优先使用 MySQL；未配置 MySQL 时，实验记录和模型版本自动落盘到 `work/adhesive_ai_lab.sqlite3`，可通过 `ADHESIVE_SQLITE_PATH` 修改位置。
- 外部任务记录默认保存在 `work/jobs`，任务命令以参数列表执行，不经过 shell 拼接。
- 一键计算会先自动检测本机的 VASP、Quantum ESPRESSO、CP2K、LAMMPS 和 GROMACS，也可在页面下拉选择求解器或填写自定义任务包装器；点击“保存为项目默认配置”后写入本地 `work/multiscale_profiles.json`。`.env` 命令仍作为高级配置和首次默认值，执行记录保存在 `work/campaign_runs`。`ADHESIVE_CAMPAIGN_MAX_PARALLEL` 的默认值为 `16`，页面可在 `1` 至 `16` 间选择；已有未结束运行时启动配置会锁定。
- 自定义包装器命令应包含 `{task_file}`，例如 `python tools/run_dft.py {task_file}`。程序会向包装器传入任务数据契约，由包装器生成并验证真实输入；直接调用求解器时，系统会检查 VASP、QE、CP2K、LAMMPS 或 GROMACS 的必要输入文件。
- 任务按“DFT/体相 MD → 界面 MD → 粗粒化”顺序推进。缺少软件、命令或输入时任务会显示为“阻塞”，不会生成或回写虚构结果。终止当前多尺度运行会保留检查点；同一候选的其他历史运行需分别终止后，启动锁才会解除。
- “外部计算任务与结果回写”默认只显示运行中、待回写、已回写和失败统计；单任务手工提交收在高级入口中，并绑定当前多尺度候选及其配方指纹。单任务引擎下拉框只显示当前可执行的项目配置，并自动带入对应命令和结果文件。页面打开时每 5 秒检测一次单任务，完成后自动解析、校验身份、按优先级回写并更新模型；页面关闭期间完成的任务会在下次打开时自动补回写。
- 需要在集群或其他工作站运行时，先在“多尺度运行方式”点击“登记并导出外部计算任务包”。该操作会在 `work/campaign_runs/<运行编号>/package` 生成可传输任务包和 ZIP 下载文件，并写入 `external_execution.json`，其中包含候选编号、配方指纹、候选库版本、任务编号、引擎、启动命令和预期结果文件。导入区以“方案候选编号”为唯一上下文，只显示当前候选的外部登记运行；本机自动运行会自动解析和回写，不可在此重复导入。切换候选会清除来源运行、任务、上传文件和高级覆盖项，但不会删除任何历史数据。选择运行后会锁定候选身份、引擎和默认结果路径，修改入口收在高级设置中。完成计算后可上传单个结果，或上传包含 `tasks/<任务编号>/<结果文件路径>` 的 ZIP 批量导入。系统在确认前显示回写目录与预期解析指标，随后核验候选编号、配方指纹和候选库版本并立即解析、回写和更新模型；对应任务会标记为“已导入并回写”，任务包身份信息不匹配时会拒绝回写。
- 批量实验 CSV 必须包含候选编号、配方指纹、候选库版本和五项输出指标。单条实验回写的候选编号默认留空且为必填项；选择候选后系统自动带入配方指纹与候选库版本。
- 项目标准启动方式仍是 `streamlit run app.py`，离线版使用 `.\run_offline.ps1`。

## 候选库

- 通过 `adhesive_ai.build_candidate_library()` 可生成覆盖 CE、PN、PI、硅橡胶、PU 及其共混/改性体系的候选表。
- 表中包含候选编号、配方指纹、候选库版本、树脂结构、动态修复单元、PDA@CeO₂ 填料、固化/后固化条件，以及耐高温性、低温韧性、粘附强度、自修复性能和空间环境稳定性等目标指标。
